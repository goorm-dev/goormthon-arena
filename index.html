대회 방식

C, C++, Java, Python3으로 알고리즘 문제를 AI와 함께 주어진 시간 내에 해결합니다. 최근 3년간 채용 평가는 알고리즘 단독 테스트에서 AI 협업을 더한 실무 생산성 평가로 이동했으며, 네이버·포스코·LG전자·LG CNS·토스·무신사 등의 채용 전형을 운영하며 축적한 기준을 그대로 적용합니다.

과제(프로젝트) 평가 AI + 알고리즘 평가 알고리즘 단독 평가

2026년 비중 — AI + 알고리즘 70%, 알고리즘 단독 20%, 과제(프로젝트) 10%

AI 활용 범위

대회에서 허용하는 내부 AI만 사용할 수 있습니다. AI는 문제 해결의 핵심 아이디어만 제공하며, 완성된 답안 코드는 반환하지 않습니다.

평가 관점

AI에게 해결 포인트와 코드 개선 방법을 질문하고, 비판적 사고로 오류와 비권장 요소를 회피했는지를 평가합니다.

출제 및 운영

주요 대기업 채용 문제를 출제하고 운영한 전문팀이 동일한 환경과 문제 스타일로 대회를 진행합니다.

평가 역량

기업에서 요구하는 실무 역량을 기준으로 평가하고, 항목별 결과를 리포트로 제공합니다.

실무형 인재

이론을 현장 문제에 바로 적용하여 가치 있는 결과물을 만드는 인재

문제해결형 인재

복잡한 요구사항을 분석하고 최적의 솔루션을 설계·구현하는 인재

미래적응형 인재

신기술을 책임감 있게 활용하며 지속 성장하는 인재

실무 능력과 이론의 통합 이론적 지식을 실제 문제 해결에 적용하고, 복잡한 문제에서 최적의 솔루션을 도출합니다.
실무 적응력 및 취업 경쟁력 현업에서 사용하는 문제 해결 접근법과 코드 최적화 기법, 대용량 데이터 처리를 다룹니다.
취업 성공 가능성 증대 실전과 동일한 환경의 문제 풀이 경험과 대회 성과가 취업·인턴십 기회로 이어집니다.
IT 인재 양성 AI 도구를 활용한 코딩 능력을 평가해 IT 산업에 필요한 역량을 강화합니다.

응시 환경

허용된 AI의 사용 범위를 관리하고 실시간 감독과 사후 검증을 진행합니다. 응시 중 화면 조작은 자동으로 감지·차단됩니다.

비인가 프로그램 및 외부 AI 실행 사전 감지 및 강제 종료 응시 전 실행 중인 외부 AI를 감지해 종료를 요청합니다.
다른 창 전환 Alt+Tab, 작업 전환 차단 시험 창 밖으로의 전환이 차단됩니다.
다중 모니터 사용 메인 디스플레이 외 자동 차단 보조 모니터를 종료하면 시험이 재개됩니다.
화면 캡처 스크린샷 및 녹화 시도 차단 시도 내역은 그대로 기록에 남습니다.

모든 부정행위 시도는 실시간으로 기록되며, 시험 종료 후 AI가 한 번 더 검증합니다

메일로 문의하기
구름톤 아레나는 어떤 대회인가요?

정식 명칭은 ‘구름톤 아레나 전국 프로그래밍 챔피언십’(구 전국 대학생 프로그래밍 경진대회)입니다. (주)구름이 주최하며, 알고리즘 실력과 AI 활용 역량을 전국 참가자들과 겨루는 대회입니다.

대회는 어떤 방식으로 진행되나요?

다양한 알고리즘 문제를 AI와 함께 주어진 시간 내에 해결하는 방식입니다. AI는 문제 해결을 위한 핵심 아이디어만 제공하며, 완성된 답안 코드를 그대로 반환하지는 않습니다.

대회 중 아무 AI나 사용할 수 있나요?

대회에서 허용하는 내부 AI만 사용할 수 있습니다. 비인가 프로그램이나 외부 AI 실행은 사전에 감지되어 강제 종료됩니다.

채점과 순위는 어떻게 결정되나요?

문항당 20점, 총 5문항으로 구성되며 각 문항 내 테스트케이스마다 일정 비율로 배점되어 부분 점수를 받을 수 있습니다. 순위는 최종 제출 고득점 → 빠른 제출 순 → 답안 제출 버튼 클릭 횟수가 적은 순으로 결정됩니다.

개인으로 신청했는데 같은 소속이 10인을 넘으면 어떻게 되나요?

참가 신청 페이지를 통해 개별 신청한 경우에도, 소속 입력 정보를 통해 10인 이상이 확인되면 단체 참가로 전환됩니다.
